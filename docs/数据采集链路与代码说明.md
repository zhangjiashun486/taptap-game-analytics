# 二、环节 1：榜单采集（crawl_boards）

**代码位置**：`01_crawl_games.py` 第 130~161 行

```python
def crawl_boards(games, tag_queue, history):
    board_types = ["hot", "new", "reserve", "pop", "sell", "in_app_event_reserve"]
    for type_name in board_types:                            # 6 个榜单逐个爬
        frm = 0                                              # from：从第几条开始
        while True:
            params = {"type_name": type_name, "from": frm, "limit": 10, "X-UA": build_xua()}
            txt = http_get("https://www.taptap.cn/webapiv2/app-top/v2/hits", params)
            data = json.loads(txt)                           # JSON 字符串 → Python 字典
            items = data["data"].get("list") or []           # 本页游戏列表（10 条）
            for item in items:
                app = item.get("app") or {}                  # 每条里的游戏对象
                if app.get("id"):
                    games.add(int(app["id"]))                # 收集 ID（set 去重）
                for tag in app.get("tags") or []:
                    value = tag.get("value")                 # 标签名，如“竞技”
                    if value and value not in tag_queue:     # 不空、不重复
                        tag_queue.append(value)              # 加进队列（滚雪球的种子）
            total = data["data"].get("total") or 0
            frm += 10                                        # 下一页
            if frm >= total:                                 # 翻完就结束
                break
            time.sleep(random.uniform(0.7, 1.2))             # 低频等待
    return games, tag_queue
```

**怎么找到的（F12）**：打开排行榜页 `https://www.taptap.cn/top/download` → F12 → Network → Fetch/XHR → 刷新/点榜单标签 → 找到 `hits?type_name=...` 请求。

**6 个榜单与参数**：

| 页面榜单 | type_name |
| --- | --- |
| 热门榜 | `hot` |
| 新品榜 | `new`（请求里可能出现 `platform=android&type_name=new`，参数顺序不同） |
| 预约榜 | `reserve` |
| 热玩榜 | `pop` |
| 热卖榜 | `sell` |
| 活动预约 | `in_app_event_reserve` |

> 为什么你“只看到 5 个”：有一条请求的 URL 是 `hits?platform=android&type_name=...`，`type_name` 被挤到后面、显示不全。点开它，Query String Parameters 里就能看到 `new`。

# 三、环节 2：标签闭合（crawl_tags，滚雪球）

**代码位置**：`01_crawl_games.py` 第 164~203 行

```python
while tag_queue and len(visited_tags) < tag_cap and ...:
    tag = tag_queue.pop(0)                    # 从队头取出一个标签
    if tag in visited_tags:                   # 已经爬过就跳过
        continue
    visited_tags.add(tag)                     # 记为已爬
    enc_tag = urllib.parse.quote(tag)         # 中文 → URL 编码（竞技 → %E7%AB%9E%E6%8A%80）
    page = 1
    while page <= page_cap:
        url = f"https://www.taptap.cn/tag/{enc_tag}"
        txt = http_get(url, {"page": page} if page > 1 else None)   # 标签页是 HTML
        ids = set(int(x) for x in re.findall(r'/app/(\d+)', txt))   # 提取游戏 ID
        if not ids: break
        games.update(ids)                                           # 合并去重
        for raw in re.findall(r'href="/tag/([^"]+)"', txt):         # 提取新标签
            value = urllib.parse.unquote(raw)
            if value and value not in visited_tags and value not in tag_queue:
                tag_queue.append(value)                             # 加回队尾（滚雪球）
        if f'?page={page+1}' not in txt: break                      # 没有下一页
        page += 1
        time.sleep(random.uniform(0.6, 1.2))
    save_state(games, visited_tags, tag_queue, history)             # 每个标签存一次档
    time.sleep(random.uniform(0.5, 0.9))
```

**关键点**：

1. 标签页返回的是 **HTML**（不是 JSON），所以用正则从文本里抠 `/app/数字` 和 `/tag/标签名`；
2. 同一款游戏在页面里会出现多次（横幅、卡片、内嵌数据），所以用 `set(...)` 去重；
3. `tag_queue` 是“待办清单”（列表，队尾进、队头出）；`visited_tags` 是“已完成清单”（集合）；
4. 每爬完一个标签 `save_state(...)` 存断点（`state.json`），中断后可续跑。

**输出**：`data/raw/closure/all_app_ids.json`（10,221 个 ID）+ `state.json`（断点）。

```python
def fetch_detail(app_id):
    headers = {"User-Agent": UA,
               "Referer": f"https://www.taptap.cn/app/{app_id}",
               "Accept": "application/json, text/plain, */*"}
    params = {"id": app_id, "X-UA": build_xua()}          # 参数名是 id，不是 app_id
    resp = requests.get("https://www.taptap.cn/webapiv2/app/v6/detail",
                        params=params, headers=headers, timeout=25)
    data = resp.json()
    if not data.get("success"):
        return None, str(data.get("data", {}).get("msg", "fail"))
    app = (data.get("data") or {}).get("app")             # 游戏数据在 data.app
    return app, "ok"
```

# 十、常见疑问

**Q1：为什么榜单用 `json.loads`，标签页用正则？**  
榜单接口返回 JSON；标签页返回 HTML。JSON 用解析器，HTML 用正则/选择器。

**Q2：`X-UA` 是什么？**  
TapTap 要求的客户端标识参数（语言/平台/设备等），浏览器请求也带；我们按同样格式生成。

**Q3：为什么 `limit=10`？**  
接口限制每页最多 10 条（试过更大值会报参数错误）。

**Q4：`from` 和 `total` 是什么？**  
`from` 是“从第几条开始”，`total` 是总条数；`from` 每次 +10，到 `total` 就结束。

**Q5：为什么需要 `sleep`？**  
礼貌爬虫：降低频率，避免给对方服务器压力和触发风控。

**Q6：断点续传存在哪？**  
`state.json`（标签阶段：已爬标签/待爬队列/已收集游戏）、`progress.json`（详情阶段：已完成/无效 ID）。

**Q7：`tag_queue` 是什么类型？**  
就是 Python 列表，用 `append`（队尾入）+ `pop(0)`（队头出）当队列用，先入先出。

# 附录 A：Python 小知识——如何搜索客户端文件里的接口字符串

## A.1 脚本做的事（三步）

```
① 遍历文件：os.walk(目录) + endswith((".js", ".html", ".asar"))
② 读成文本：open(文件, encoding="utf-8", errors="ignore").read()
③ 搜索并截上下文：re.finditer(re.escape(关键词), 文本) → m.start()/m.end()
```

**工具位置**：`data_server/jobs/tools/scan_client_strings.py`（已带完整注释，可命令行运行）。

**运行方式**：

```powershell
$env:PYTHONIOENCODING="utf-8"
& "data_server\.venv\Scripts\python.exe" "data_server\jobs\tools\scan_client_strings.py" --pattern "app/v6/detail"
```

结果保存到 `data/output/client_scan_result.json`。

## A.2 核心函数逐行解释

```python
import os, re
ROOT = r"<TapTap 客户端 resources 目录>"
PATTERNS = ["app/v6/detail", "pc-game/v2/list"]

def scan_file(fp, pats):
    txt = open(fp, encoding="utf-8", errors="ignore").read()   # 把文件当文本读进来
    hits = []
    for pat in pats:                                          # 每个关键词
        for m in re.finditer(re.escape(pat), txt):            # 找出所有出现位置
            ctx = txt[max(0, m.start()-60): m.end()+80]       # 截取命中处前后文
            hits.append((pat, os.path.basename(fp), ctx))
            break                                             # 只跳出【内层】循环
    return hits

for dp, _, fns in os.walk(ROOT):                              # 递归遍历目录
    for fn in fns:
        if fn.endswith((".js", ".html", ".asar")):            # 只要这三类文件
            for pat, f, ctx in scan_file(os.path.join(dp, fn), PATTERNS):
                print(pat, f, ctx[:120])
```

| 写法 | 含义 | 大白话 |
| --- | --- | --- |
| `os.walk(ROOT)` | 递归遍历目录 | 把 resources 下面所有层级的文件都走一遍 |
| `fn.endswith((...))` | 判断后缀 | 只要 JS/HTML/ASAR，忽略图片和二进制 |
| `open(..., errors="ignore")` | 读文本、忽略解码错误 | `.asar` 里有二进制，忽略掉不能解码的字节 |
| `re.escape(pat)` | 转义正则特殊字符 | 让 `.`、`+`、`?` 按“原文字符”匹配 |
| `re.finditer(...)` | 返回所有匹配对象（含位置） | 每个 `m` 能取 `.group()`、`.start()`、`.end()` |
| `txt[start:end]` | 字符串切片 | 截取命中处前后 60/80 个字符看上下文 |
| `break` | 跳出当前（内层）循环 | 外层关键词循环会继续 |

## A.3 `break` 只跳出内层（常见疑问）

```python
for pat in ["A", "B"]:                 # 外层
    for m in re.finditer(pat, text):   # 内层
        print(pat, m.group())
        break                          # 只跳出内层；外层会继续跑到 B
```

演示输出（两个关键词都会被搜到）：

```
A A
B B
```

如果想跳出两层：用标志位或 `return`；如果不想只取第一条：去掉 `break`。

## A.4 `finditer` / `findall` / `search` 的区别

| 写法 | 返回 | 有位置吗 | 用途 |
| --- | --- | --- | --- |
| `txt.find(pat)` | 第一次出现的下标（-1 表示没有） | — | 只判断有没有 |
| `re.search(pat, txt)` | 第一个匹配对象 | ✅ | 只要第一条 |
| `re.findall(pat, txt)` | 所有匹配的**文字**列表 | ❌ | 只要匹配内容 |
| `re.finditer(pat, txt)` | 所有匹配的**对象**迭代器 | ✅ | 需要位置/上下文（本项目用法） |

## A.5 常见问题

**Q1：为什么 `.asar` 也能搜？**  
`.asar` 是 Electron 的打包文件（JS 文本拼接 + 头部索引），内容是明文；用 `errors="ignore"` 当文本读就能搜到接口字符串。

**Q2：为什么不直接用 VS Code 搜索？**  
手工搜索也可以（Ctrl+Shift+F）；脚本适合批量、可重复、把结果存成 JSON 供后续使用。

**Q3：为什么每个文件每个词只留一条？**  
打包后的 JS 很啰嗦，同一路径可能重复几十次；一条上下文足够判断“这个接口在这个文件里存在”，避免输出刷屏。改成全部命中就去掉 `break`。

```javascript
const WEB_APP_XUA_ALLOWED_PATHS = new Set(["/app/v6/detail"]), ...

function canUseWebAppXua(url, flag) {
    if (!flag) return false;
    const u = new URL(url, "http://localhost");
    return u.origin === "http://localhost" && WEB_APP_XUA_ALLOWED_PATHS.has(u.pathname);
}
```

**逐词解读**：

- `WEB_APP`：网页端身份；
- `XUA`：请求里的 `X-UA=V=1&PN=WebApp&...` 参数；
- `ALLOWED_PATHS`：允许的路径白名单；
- `new Set([...])`：JavaScript 集合（白名单）；
- `.has(u.pathname)`：判断路径是否在白名单里。

**结论（推断）**：客户端允许对 `/app/v6/detail` 使用 WebApp X-UA 身份调用。
