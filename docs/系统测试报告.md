# 四、测试中发现的问题与解决

| # | 问题 | 原因 | 解决 |
| --- | --- | --- | --- |
| 1 | 端口 8080 被占用 | Steam 的 steamwebhelper 远程调试端口 | 开发时退出 Steam；测试时用 18080 |
| 2 | JDK 报“Unable to establish loopback connection” | Windows 临时目录过长导致 AF_UNIX 失败 | 设置 TEMP/TMP=C:\temp 或 `-Djava.io.tmpdir=C:\temp` |
| 3 | MySQL 5.6 连接失败 | Spring Boot 4 默认驱动 9.x 不支持 5.6 | 换用 mysql-connector-java 5.1.49 |
| 4 | 冷启动推荐出现“10 分但没评论”的小游戏 | 只按评分排序 | 加 `review_count >= 1000` 门槛 |
| 5 | 标签页提取到大量重复 ID | 同一游戏在页面出现多次 | `set(...)` 去重 |
| 6 | ECharts 打包体积 1.1MB（构建警告） | 全量引入 ECharts | 课程演示可接受；后续可按需引入 |
