# 部署与启动说明

**项目**：TapTap 游戏数据分析与智能推荐平台（HunuProjec2）

---

# 一、系统组成与端口

| 模块 | 技术 | 端口 | 说明 |
| --- | --- | --- | --- |
| data_server | Python + FastAPI | 8081 | 数据采集/分析/统计服务（只给 base_server 调） |
| base_server | Java + Spring Boot | 8080 | 唯一对外出口：登录、游戏、行为、推荐、问答、管理统计 |
| client_server | Vue3 + Vite | 8001 | 用户端前端 |
| admin_server | Vue3 + Vite | 8002 | 管理端前端 |
| MySQL | 5.6（虚拟机） | 3306 | 业务数据库 taptap_course |
| HDFS | Hadoop（虚拟机） | 50070(WebHDFS) | 原始数据归档（/taptap） |

---

# 二、环境要求

| 项 | 要求 |
| --- | --- |
| JDK | 17（本项目：<JDK 17 安装目录>） |
| Maven | 3.9.x |

# 三、启动顺序（建议）

## 第 1 步：启动虚拟机

- 启动 VMware 中的 Linux 虚拟机；
- 确认 MySQL 与 HDFS 正常：
  - `Test-NetConnection 192.168.100.101 -Port 3306`
  - 浏览器访问 `http://192.168.100.101:50070`

## 第 2 步（可选）：数据采集与分析

如果需要重新采集/分析（已有数据可跳过）：

```powershell
$env:TAPTAP_DB_PASSWORD = "你的密码"
cd C:\java\HunuProjec2

# 爬虫（低频、断点续传）
python data_server/jobs/crawler/01_crawl_games.py
python data_server/jobs/crawler/02_crawl_details.py

# 入库 + 聚类
python data_server/jobs/import_games.py
python data_server/jobs/cluster_games_v2.py     # 加 --dry-run 只演示不写库

# 归档到 HDFS
python data_server/jobs/upload_to_hdfs.py

# （可选）生成演示行为数据
python data_server/jobs/tools/simulate_behavior.py
```

## 第 3 步：启动 data_server（Python，8081）

```powershell
$env:TAPTAP_DB_PASSWORD = "你的密码"
cd C:\java\HunuProjec2\data_server
.venv\Scripts\python.exe run.py
```

验证：浏览器打开 `http://127.0.0.1:8081/api/health`

## 第 4 步：启动 base_server（Java，8080）

```powershell
# 退出 Steam（释放 8080）
$env:TEMP = "C:\temp"; $env:TMP = "C:\temp"
$env:TAPTAP_DB_PASSWORD = "你的密码"
cd C:\java\HunuProjec2\base_server
mvn spring-boot:run
```

验证：`http://127.0.0.1:8080/api/health`、`/api/health/db`

## 第 5 步：启动两个前端

```powershell
# 用户端（8001）
cd C:\java\HunuProjec2\client_server
npm run dev

# 管理端（8002）
cd C:\java\HunuProjec2\admin_server
npm run dev
```

- 用户端：http://localhost:8001
- 管理端：http://localhost:8002

# 六、常见问题排查

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| Port 8080 already in use | Steam 的 steamwebhelper 占用 | 退出 Steam，或临时 `SERVER_PORT=18080` |
| Unable to establish loopback connection | JDK 临时目录过长（AF_UNIX） | TEMP/TMP=C:\temp 或 `-Djava.io.tmpdir=C:\temp` |
| 数据库连接失败（MySQL 5.6） | 驱动版本不兼容 | 使用 mysql-connector-java 5.1.49 |
| 前端请求 401 | 未登录/token 过期 | 重新登录 |
| 前端请求 403 | 用普通用户访问管理端接口 | 用 admin 登录管理端 |
| 前端跨域报错 | 后端 CORS 白名单不含前端域名 | 确认从 8001/8002 访问（已配置） |
| npm 安装慢/失败 | 网络 | 使用 `--registry=https://registry.npmmirror.com` |

# 七、打包与部署（可选）

```powershell
# 前端打包（生成 dist 目录，交给 Nginx 或静态服务器）
cd client_server && npm run build
cd ../admin_server && npm run build

# Java 打包（生成可执行 jar）
cd ../base_server
mvn -DskipTests package
java -Djava.io.tmpdir=C:\temp -jar target/base_server-0.0.1-SNAPSHOT.jar
```
